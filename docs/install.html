01 / 推荐

油猴脚本

适合已经安装 Tampermonkey 的用户。安装一次，后续由油猴按设置检查更新。

安装 / 更新油猴脚本
  1. 先安装 Tampermonkey。
  2. 点击上面的按钮，在油猴安装页确认。
  3. 刷新知乎问题页，右下角开始使用。

没有弹出安装页？下载 .user.js 后，从油猴管理面板导入即可。旧版本手动粘贴安装的用户，建议从这个入口重新安装一次。

02 / Chrome · Edge

浏览器扩展

不需要油猴。当前提供开发者模式加载版，设置保存在浏览器本地。

下载扩展安装包
  1. 解压 ZIP，找到 manifest.json 所在目录。
  2. 打开 chrome://extensions/ 或 edge://extensions/。
  3. 启用开发者模式，选择“加载已解压的扩展程序”。

更新：下载新包，解压覆盖原安装目录，在扩展管理页点击“重新加载”，再刷新知乎。此版本不会后台自动替换扩展代码。

更新与排查

升级前通常不用卸载，可保留已有本地设置。油猴和扩展二选一启用，避免重复面板。
