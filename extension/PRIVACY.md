# 隐私说明

更新日期：2026-11-27。项目作者和维护者：jasonLi。

本工具的单一用途是在用户打开的知乎提问页面，将指定数量的可见回答导出为本地 PNG、WebP、SVG、HTML 或 PDF 文件。

## 处理哪些数据

- 读取当前提问页面中的标题、作者、回答链接、正文和配图，仅用于当前导出任务。
- Chrome 扩展把用户设置的回答数、清晰度、格式、PDF图片不跨页选项、HTML交互内容选项和面板收起状态保存在 `chrome.storage.local`，油猴版保存在Tampermonkey的GM存储中。设置不跨设备同步。
- 图片和导出文件在浏览器本地内存中处理；生成文件后由用户点击下载。任务结束后页面资源会随关闭/刷新释放。

## 网络请求

- 开启HTML交互选项时，使用当前知乎页面的登录状态向知乎同源接口读取可访问的段评、回复和视频播放信息；不读取或导出Cookie/Token。评论正文和昵称会写入导出文件；受限或未完整读取的内容会标注。
- 开启HTML交互选项时，从HTTPS知乎媒体域名zhihu.com、zhimg.com、vzuu.com及子域下载可读取的音视频，保存到ZIP中的media目录；不携带Cookie，不跟随重定向。下载服务器可获得正常网络访问信息。已成功保存的音视频支持解压后离线播放，受限、超限或不支持的资源会标注失败。
- 正常滚动、展开回答会触发知乎页面本身的加载请求。
- 为把配图写入可下载图片，扩展后台从 HTTPS 知乎图片域名 `zhimg.com` 及其子域读取配图，不携带 Cookie，不跟随重定向。网站仍能按正常网络访问获得请求 IP 等信息。
- 油猴版本通过 Tampermonkey 从固定的 jsDelivr 地址加载 html2canvas 1.4.1 和 jsPDF 4.2.1；扩展版本已内置这些依赖，不从 CDN 执行代码。
- 本项目不设置自建服务器，不向项目作者或第三方分析服务上传回答正文、图片、浏览记录或导出文件，不包含遥测、广告或账号登录功能。
- 安装/更新页在本地生成GitHub链接；用户点击下载或最新发布入口后访问对应公开仓库。已绑定更新地址的油猴脚本由Tampermonkey按用户设置向GitHub检查元数据并下载新版本。扩展不会后台查询版本或静默替换本地代码。

## 权限用途

- 知乎页面访问：读取当前页面并显示导出面板，适配知乎站内导航。
- 知乎图片及媒体域名访问：读取配图和音视频，避免跨域限制导致离线导出缺失。
- `storage`：保存本地默认设置。

不申请 Cookie 读取、浏览历史、所有网站访问或下载管理权限。

## 数据删除与反馈

卸载扩展会清除扩展本地设置；已下载文件由用户自行保管或删除。油猴版本只持久存储上述本地偏好，不持久存储回答正文。

隐私相关问题请在本 GitHub 仓库提交 Issue。请不要上传账号 Cookie、Token 或含私人内容的完整导出文件。
